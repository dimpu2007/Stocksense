# StocVue

A pastel blue and black themed inventory management system built with Flask and SQLAlchemy.

## Features
- Secure login and registration flow
- Password reset with OTP demo flow
- Dashboard KPIs and stock analytics
- Products, receipts, deliveries, transfers, and adjustments
- SQLite database persistence
- Professional dashboard with Chart.js charts
